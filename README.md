# МДК.04.02 — лабораторные работы

Единый статический стенд для 22 лабораторных работ по МДК.04.02 «Обеспечение качества функционирования компьютерных систем». В каждой работе есть исходные данные, краткая теория, профессиональная ситуация, шесть логических этапов, самопроверка и отдельный шаблон отчёта Word.

## Состав

- 7 семестр: ЛР1–ЛР10, блок «Надёжность и качество в эксплуатации», по 5 баллов;
- 8 семестр: ЛР11–ЛР21 по 4 балла, ЛР22 — 6 баллов, блок «Защита компьютерных систем»;
- суммарно: 22 работы и 100 баллов;
- сдача выполняется только в LMS одним файлом `.docx`;
- сайт не принимает файлы, не хранит данные студентов и не проверяет ответы автоматически.

## Локальный запуск

Требуются Node.js 22+ и pnpm 11.

```bash
pnpm install
pnpm dev
```

Полная проверка проекта:

```bash
pnpm run check
pnpm run test:e2e
```

Сборка создаётся в `dist/`:

```bash
pnpm build
pnpm preview
```

## Ссылка на LMS

Ссылка перехода в LMS задаётся в файле `src/config.ts` в поле `lmsUrl`. Сейчас используется тот же адрес, что и в референсном практикуме: `https://synergy.ru/students`.

## Структура данных

Содержимое всех работ хранится в `src/data/labs.json`. Скрипт `scripts/validate-content.mjs` проверяет точное количество работ, распределение баллов, обязательные поля, структуру LMS-инструкции, отсутствие рубрик оценивания и наличие 22 шаблонов Word.
