# МДК.04.02 — лабораторные работы

22 связанные работы по обеспечению качества функционирования компьютерных систем. Содержание 2.0.0-lab-context. Основа интерфейса — 2026-lab-shablone 0.1.0, коммит 7bdc532c50c2559ffd3ee7fdcb0fba7edf05ebac.

Сохранены названия, нумерация, исходные числовые данные и баллы: ЛР01–ЛР10, 7 семестр, 50 баллов; ЛР11–ЛР22, 8 семестр, 50 баллов. Для каждого из 30 вариантов сохраняются критичная функция, активы и профиль. Общие учебные эпизоды отрабатывают метод; обязательное предметное обоснование переносит результат на конкретную область без выдумывания происшедших в ней инцидентов.

## Запуск и проверки

Node.js 24, pnpm 11, Python 3 с lxml для генерации DOCX.

```sh
pnpm install --frozen-lockfile
pnpm run dev
pnpm run check
pnpm run test:e2e
```

Браузерные проверки используют отдельный порт 5399. Для установки браузера: `pnpm exec playwright install chromium`. Production-сборка: `pnpm run build`; просмотр: `pnpm run preview`. Базовый путь `/2026-OKFKS-lab/` сохранён.

## Изменение содержания

Авторские источники: `authoring/context.mjs`, `authoring/step-results.mjs`, `authoring/labels.mjs`. `authoring/labs-baseline.json` фиксирует исходные реквизиты, условия и задания. `authoring/lecture-reference.json` — снимок опубликованного лекционного курса для проверки ссылок.

```sh
node scripts/adapt-context.mjs
python scripts/update-reports.py
python scripts/refresh-source-packs.py
pnpm run check
pnpm run test:e2e
```

Генерация перезаписывает производные `src/data/labs.json`, методические данные, описания и формы. Редактируйте авторские источники. Старые генераторы `generate_reports.py` и `generate_subject_areas.py` сохранены как исторические; для новой версии используйте команды выше.

`docs/laboratory-descriptions.txt` — готовые описания всех 22 работ по структуре пользовательского образца: цель, литература, инструменты, задание, связь с лекцией и другими работами, пример, чек-лист и критерии. Максимальные баллы сохранены, распределение по критериям является авторской конкретизацией. Самопроверка не выставляет оценку автоматически.

## Комплекты и формы

На странице работы скачивается один ZIP своего варианта. В нём HTML, персонализированный DOCX и MD/CSV только данной ЛР. Комплект варианта содержит 22 работы. В настройках преподавателя архив за 7 семестр содержит 300 наборов, за 8 — 360, за весь курс — 660. Каждый набор включает номер варианта, собственную предметную область и профиль. CSV: UTF-8 с BOM, разделитель `;`. Распакуйте архив полностью, сохранив общую папку assets.

Формы основаны на сохранённом образце `authoring/report-reference.docx`. Изменён только `word/document.xml`; остальные части пакета сохранены побайтно. Times New Roman 12 пт, A4, поля 3 / 1,5 / 2 / 2 см. Рисунки предусмотрены там, где требуется схема. Поля ответов пусты. При отдельном скачивании DOCX вариант заполняется вручную; внутри ZIP он уже указан.

Локально DOCX проверены через Word и PNG: см. `docs/quality-report.md`. Утилита навыка render_docx.py потребовала отсутствующий LibreOffice; использован установленный Word через `scripts/render_reports.ps1`. Файлы рендера служат проверке, не заменяют редактируемые отчёты.

## Связь с лекциями и настройки

58 ссылок ведут на реальные разделители вопросов семи лекций. Для каждой работы показаны применение теории, предыдущие результаты и передача следующему этапу. Полная карта: `docs/lecture-lab-map.json`.

Настройки, тема и выбор варианта сохраняются локально в браузере. Общая ссылка на материалы и LMS задаётся в `src/config.ts`. Сдача — один DOCX через LMS; сайт не принимает персональные файлы и не хранит ответы студентов на сервере.
