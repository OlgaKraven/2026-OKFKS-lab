# МДК.04.02 — лабораторные работы

Единый статический стенд для 22 лабораторных работ по МДК.04.02 «Обеспечение качества функционирования компьютерных систем». В каждой работе есть исходные данные, краткая теория, пример по пяти характеристикам, самопроверка и отдельный шаблон отчёта Word.

## Состав

- 7 семестр: ЛР1–ЛР10, блок «Надёжность и качество в эксплуатации», 50 баллов;
- 8 семестр: ЛР11–ЛР22, блок «Защита компьютерных систем», 50 баллов;
- суммарно: 22 работы и 100 баллов;
- 30 сквозных предметных областей, сгруппированных по пять вариантов;
- для каждой области доступен отдельный ZIP-пакет с исходными данными всех 22 работ;
- сдача выполняется только в LMS одним файлом `.docx`;
- сайт не принимает файлы, не хранит данные студентов и не проверяет ответы автоматически.

## Локальный запуск

Требуются Node.js 22+ и pnpm 11.

```bash
pnpm install
pnpm run generate:subjects
pnpm dev
```

Полная проверка проекта:

```bash
pnpm run check
pnpm run test:e2e
```

Сборка создаётся в `dist/`:

```bash
pnpm build
pnpm preview
```

## Ссылка на LMS

Ссылка перехода в LMS задаётся в файле `src/config.ts` в поле `lmsUrl`: `https://lms.synergy.ru/`.

## Структура данных

Содержимое работ хранится в `src/data/labs.json`, каталог вариантов — в `src/data/subject-areas.json`. Скрипт `scripts/generate_subject_areas.py` создаёт 30 изолированных ZIP-пакетов. Валидатор проверяет работы, группы, пять характеристик, отсутствие дублей и наличие шаблонов Word.
