# Руководство преподавателя

## Перед выдачей курса

1. Проверьте формулировки и выданные учебные наборы в `src/data/labs.json`.
2. Проверьте ссылку перехода в LMS в `src/config.ts`.
3. Убедитесь, что в настройках репозитория GitHub Pages выбран источник GitHub Actions.
4. Запустите `pnpm run check` и `pnpm run test:e2e`.
5. После публикации откройте несколько прямых маршрутов вида `#/lab/01` и проверьте скачивание соответствующего DOCX.

## Настройка ссылки LMS

Откройте `src/config.ts` и заполните поле:

```ts
lmsUrl: 'https://lms.synergy.ru/'
```

Не добавляйте на сайт формы загрузки: переход к сдаче выполняется по внешней ссылке LMS.

## Обновление содержания

После правок в `src/data/labs.json` обязательно запустите валидатор. Он обнаружит изменение точных названий, неверную сумму баллов, потерю обязательных разделов, запрещённые требования по времени, внешние опасные действия и отсутствие шаблонов отчётов.

Шаблоны Word создаются скриптом `scripts/generate_reports.py` из утверждённого титульного листа. Исходный эталон не изменяется; содержательная часть добавляется после титульной страницы.

## Безопасные границы

Работы рассчитаны на выданные карточки, журналы, локальные макеты и учебные симуляции. Они не требуют запуска вредоносного кода, атак на реальные узлы, обработки реальных секретов или публикации персональных данных.
