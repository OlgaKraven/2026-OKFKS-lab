# Отчёт о проверке качества

Дата финальной проверки: 4 сентября 2026 года.

## Автоматические проверки

- `pnpm run check`: успешно;
- линтер `oxlint`: успешно;
- модульные тесты Vitest: 3 из 3;
- TypeScript: ошибок нет;
- валидатор содержания: 22 работы, по 50 баллов в каждом семестре и 100 баллов всего, 30 предметных областей, 30 ZIP-наборов и 22 DOCX-шаблона;
- production-сборка Vite и проверка `dist/`: успешно;
- Playwright: 12 из 12 сценариев в профилях desktop Chromium и Pixel 7;
- проверены перенос действий в итоговую карточку, ссылка на LMS, сохранение выбранного варианта и загрузка набора только для него;
- валидатор подтверждает отсутствие подписей ОК/ПК, повторов между блоками задания и маршрута, а также точных дублей в контрольных списках.

## Проверка предметных областей

- создано 30 уникальных областей, распределённых по шести профилям по пять вариантов;
- каждый профиль содержит ровно пять однотипных характеристик;
- для каждой области сформирован отдельный ZIP с паспортом системы, таблицей характеристик и 22 файлами исходных данных по лабораторным работам;
- каждый набор содержит данные только выбранной предметной области.

## Проверка шаблонов Word

- создано 22 отдельных файла `.docx` на основе официального титульного листа;
- структурно проверены все 22 пакета Word: документная часть читается, баллы соответствуют карте курса, поле предметной области присутствует, подписи ОК/ПК отсутствуют;
- визуальный рендер Word → PDF → PNG в текущей среде не выполнен, поскольку LibreOffice/`soffice` не установлен;
- контрольный исходный титульный шаблон не изменён.

## Ручная проверка интерфейса

- главная страница и страница ЛР1 проверены визуально во встроенном браузере;
- на странице работы подтверждены: отсутствие кнопок в `lab-hero`, пять карточек характеристик между теорией и заданием, отсутствие повторного маршрута и блока практического результата, наличие действий в `lab-summary`;
- на главной странице подтверждены 100 баллов, 30 вариантов и распределение по 50 баллов между семестрами.

## Известные ограничения

- сборка выдаёт только информационные предупреждения Vite о размере основного JavaScript-фрагмента и разрешении веб-шрифта во время сборки;
