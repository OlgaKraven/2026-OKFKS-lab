# SA19 · ЛР 17 · Разграничение прав доступа к ресурсам системы

**Предметная область:** Экзаменационный терминал
**Система:** `OKFKS-SA19`
**Критичная функция:** запуск и сдача учебного задания
**Профиль:** Автоматизированные рабочие места (варианты 16–20)

## Рабочая ситуация

В системе учёта заявок роли создавались по мере появления задач, поэтому часть пользователей получила лишние права. Специалист должен построить ролевую матрицу, устранить конфликт полномочий и проверить типовые действия.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Целевая готовность | 99,0 % в учебное время |
| C2 | Время восстановления | не более 4 часов |
| C3 | Допустимая потеря данных | не более 24 часов |
| C4 | Предел производительности | запуск до 120 с |
| C5 | Контроль и хранение доказательств | состояние каждые 5 минут; журнал 30 дней |

## Исходные данные

Работайте только с приведённым учебным набором. Все имена, адреса, события и конфигурации синтетические; дополнительный поиск не требуется.

### Роли

| ID | Роль | Duties |
| --- | --- | --- |
| R1 | Заявитель | создать и просматривать свою заявку, добавить комментарий до закрытия |
| R2 | Исполнитель | просматривать назначенные заявки, менять статус и добавлять рабочий комментарий |
| R3 | Руководитель | распределять заявки, видеть отчёт подразделения, утверждать закрытие |
| R4 | Аудитор | читать все заявки и журналы без изменения |
| R5 | Администратор | управлять учётными записями и ролями, не утверждать деловые операции |

### Доступные ресурсы

своя заявка

чужая заявка

назначенная заявка

рабочий комментарий

отчёт подразделения

журнал аудита

учётная запись

назначение роли

### Допустимые действия

C — создать

R — прочитать

U — изменить

D — удалить

A — утвердить

### Бизнес-правила

| ID | Правило |
| --- | --- |
| B1 | пользователь не утверждает закрытие заявки, которую исполнял |
| B2 | журнал аудита нельзя изменять через прикладные роли |
| B3 | аудитор имеет только чтение |
| B4 | назначение ролей доступно администратору, но журналирует старое и новое значение |
| B5 | удаление закрытых заявок не предусмотрено ни одной ролью |
| B6 | неуказанное действие по умолчанию запрещено |
