# SA20 · ЛР 20 · Тестирование защиты программного обеспечения по заданному набору проверок

**Предметная область:** Мобильное учебное рабочее место
**Система:** `OKFKS-SA20`
**Критичная функция:** защищённый доступ к учебным сервисам
**Профиль:** Автоматизированные рабочие места (варианты 16–20)

## Рабочая ситуация

Перед приёмкой учебного веб-приложения «Заявки» специалист должен проверить защитные требования. Вместо реального сервера выданы безопасные карточки запросов и зафиксированные ответы версии 1.4.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Целевая готовность | 99,0 % в учебное время |
| C2 | Время восстановления | не более 4 часов |
| C3 | Допустимая потеря данных | не более 24 часов |
| C4 | Предел производительности | запуск до 120 с |
| C5 | Контроль и хранение доказательств | состояние каждые 5 минут; журнал 30 дней |

## Исходные данные

Работайте только с приведённым учебным набором. Все имена, адреса, события и конфигурации синтетические; дополнительный поиск не требуется.

### Условие безопасности

Тестирование выполняется только по готовым карточкам. Не нужно отправлять запросы на сайты, подбирать данные, обходить доступ или использовать специальные полезные нагрузки.

### Требования

| ID | Text |
| --- | --- |
| R1 | пустое обязательное поле отклоняется с понятным сообщением без технических деталей |
| R2 | поле Тема принимает от 3 до 120 символов включительно |
| R3 | роль viewer видит только свои заявки |
| R4 | имя вложения отображается как текст; нейтральные угловые скобки не интерпретируются как разметка |
| R5 | допустимые расширения вложений: pdf, docx, png; максимальный размер 5 МБ |
| R6 | после завершения сессии повторное открытие защищённой страницы требует входа |
| R7 | ошибка приложения выдаёт пользователю код обращения, а подробность сохраняет во внутреннем журнале |
| R8 | изменение статуса журналируется с пользователем, старым и новым значением |

### Шкала серьёзности

критическая — позволяет получить или изменить чужие защищаемые данные

значительная — раскрывает внутренние сведения или нарушает обязательный контроль

умеренная — ослабляет проверку, но прямой доступ к чужим данным не подтверждён

низкая — локальная проблема представления или удобства
