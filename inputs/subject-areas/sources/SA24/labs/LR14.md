# SA24 · ЛР 14 · Настройка средства антивирусной защиты и проверка его действия

**Предметная область:** Сервис удалённого доступа
**Система:** `OKFKS-SA24`
**Критичная функция:** защищённое подключение к учебной сети
**Профиль:** Сетевые и защитные сервисы (варианты 21–25)

## Рабочая ситуация

Для учебного компьютерного класса требуется настроить политику защиты в табличном симуляторе. Настройка должна блокировать опасные учебные события, не мешать разрешённым действиям и формировать достаточный журнал.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Целевая готовность | 99,9 % |
| C2 | Время восстановления | не более 45 минут |
| C3 | Допустимая потеря данных | конфигурация не старше 24 часов |
| C4 | Предел производительности | задержка до 50 мс |
| C5 | Контроль и хранение доказательств | потоки и отказы ежеминутно; журнал 90 дней |

## Исходные данные

Работайте только с приведённым учебным набором. Все имена, адреса, события и конфигурации синтетические; дополнительный поиск не требуется.

### Условие симуляции

Работа выполняется в таблице. Учебные маркеры не являются файлами и не должны создаваться или запускаться.

### Требования политики

| ID | Требование |
| --- | --- |
| R1 | защита в реальном времени включена |
| R2 | неизвестные исполняемые объекты из съёмных носителей помещаются в карантин |
| R3 | подписанные приложения из каталога Approved разрешаются |
| R4 | отключение защиты пользователем запрещено |
| R5 | неудачные обновления фиксируются и создают уведомление администратора |
| R6 | архивы глубже трёх уровней отмечаются для отдельной проверки |
| R7 | журнал содержит узел, событие, действие и основание правила |

### Доступные настройки

| Setting | Values |
| --- | --- |
| realTime | ON; OFF |
| removableUnknown | ALLOW; LOG; QUARANTINE |
| approvedSigned | ALLOW; QUARANTINE |
| userCanDisable | YES; NO |
| updateFailure | IGNORE; LOG; LOG_AND_ALERT |
| archiveDepth | 1; 3; 5 |
| logDetail | BASIC; FULL |

### Исходная конфигурация

Real Time: ON

Removable Unknown: LOG

Approved Signed: QUARANTINE

User Can Disable: YES

Update Failure: LOG

Archive Depth: 5

Log Detail: BASIC

### Карточки проверок

| ID | Событие | Источник | Signature |
| --- | --- | --- | --- |
