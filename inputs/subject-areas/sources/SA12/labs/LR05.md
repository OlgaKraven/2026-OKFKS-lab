# SA12 · ЛР 05 · Реализация контроля входных данных в заданном модуле

**Предметная область:** Синхронизация реестра студентов
**Система:** `OKFKS-SA12`
**Критичная функция:** передача актуальных учётных записей
**Профиль:** Учётные и интеграционные сервисы (варианты 11–15)

## Рабочая ситуация

Модуль регистрации заявок оборудования принимает объект без проверок. Из-за пустых полей, неверных кодов и недопустимых значений заявки попадают в очередь обработки и вызывают повторные ошибки. Нужно реализовать локальную функцию проверки и испытать её на выданном наборе без сетевых запросов.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Целевая готовность | 99,9 % |
| C2 | Время восстановления | не более 1 часа |
| C3 | Допустимая потеря данных | не более 1 часа |
| C4 | Предел производительности | задержка очереди до 60 с |
| C5 | Контроль и хранение доказательств | контроль очереди каждую минуту; журнал 90 дней |

## Исходные данные

Работайте только с приведённым учебным набором. Все имена, адреса, события и конфигурации синтетические; дополнительный поиск не требуется.

### Контракт модуля

Вход: объект request

Выход: объект { ok: boolean, errors: string[] }

Safety: функция не изменяет входной объект, не читает файлы и не отправляет данные в сеть

### Правила полей

| Поле | Required | Правило | Valid Example | Error Code |
| --- | --- | --- | --- | --- |
| equipmentId | да | строка PC-001…PC-120; ровно три цифры | PC-037 | E_EQUIPMENT_ID |
| temperatureC | да | число от -10.0 до 85.0 включительно; не NaN | 24.5 | E_TEMPERATURE |
| severity | да | одно из low, medium, high | medium | E_SEVERITY |
| description | да | после trim от 10 до 200 символов | Шум вентилятора при запуске | E_DESCRIPTION |
| contactEmail | нет | пустое допустимо; иначе одна @, непустые части и точка после @ | student@example.edu | E_EMAIL |
| requiresShutdown | да | логическое значение | нет | E_SHUTDOWN |
| severity+requiresShutdown | да | если severity=high, requiresShutdown должно быть true | high + true | E_RELATION |
