# SA12 · ЛР 03 · Расчёт коэффициента готовности и оценка соответствия требованию

**Предметная область:** Синхронизация реестра студентов
**Система:** `OKFKS-SA12`
**Критичная функция:** передача актуальных учётных записей
**Профиль:** Учётные и интеграционные сервисы (варианты 11–15)

## Рабочая ситуация

Для сервера электронного расписания OKFKS-SA12 установлен норматив готовности. По месячной сводке нужно вычислить фактический коэффициент, принять решение о соответствии и, если требуется, выбрать улучшение, которое помещается в установленный бюджет.

## Исходные данные

Работайте только с приведённым учебным набором. Все имена, адреса, события и конфигурации синтетические; дополнительный поиск не требуется.

### Требование

ID: REQ-AV-01

Text: Коэффициент готовности за отчётный период должен быть не ниже 0.9950

Comparison Rule: соответствует, если Kг ≥ 0.9950

### Формула

Kг = Tработы / (Tработы + Tвосстановления)

### Период наблюдения

Calendar Hours: 720

Planned Maintenance Hours: 6

Правило: плановое обслуживание исключается из базы сравнения

### Зафиксированные отказы

| ID | Cause | Recovery Hours |
| --- | --- | --- |
| F01 | перезапуск службы после сбоя конфигурации | 0.3 |
| F02 | восстановление дискового зеркала | 1.6 |
| F03 | замена вентилятора и контроль запуска | 2.4 |
| F04 | исправление ошибочного маршрута | 0.9 |

### Правила расчёта

Tвосстановления равно сумме длительностей F01–F04.

Tработы = календарное время − плановое обслуживание − Tвосстановления.

Знаменатель формулы должен совпасть с календарным временем за вычетом планового обслуживания.

Итоговый коэффициент показывается не менее чем с четырьмя знаками после запятой.
