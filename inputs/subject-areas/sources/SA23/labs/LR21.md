# SA23 · ЛР 21 · Проверка защищённости системы по регламенту и оформление заключения

**Предметная область:** Контроллер Wi-Fi
**Система:** `OKFKS-SA23`
**Критичная функция:** подключение авторизованных учебных устройств
**Профиль:** Сетевые и защитные сервисы (варианты 21–25)

## Рабочая ситуация

Перед вводом учебного файлового сервера OKFKS-SA23 в эксплуатацию комиссия запросила заключение о защищённости. Специалист получает регламент и пакет синтетических доказательств по состоянию на 2026-08-31.

## Пять характеристик профиля

| Код | Характеристика | Значение |
| --- | --- | --- |
| C1 | Целевая готовность | 99,9 % |
| C2 | Время восстановления | не более 45 минут |
| C3 | Допустимая потеря данных | конфигурация не старше 24 часов |
| C4 | Предел производительности | задержка до 50 мс |
| C5 | Контроль и хранение доказательств | потоки и отказы ежеминутно; журнал 90 дней |

## Исходные данные

Работайте только с приведённым учебным набором. Все имена, адреса, события и конфигурации синтетические; дополнительный поиск не требуется.

### Описание системы

OKFKS-SA23 хранит учебные задания и отчёты. Доступ имеют 120 студентов, 12 преподавателей и два администратора. Проверка проводится только по пакету E01–E14.

### Фрагмент регламента

| ID | Critical | Требование |
| --- | --- | --- |
| R1 | да | для каждого активного пользователя есть владелец и действующее основание доступа |
| R2 | да | административные учётные записи персональные; общие записи запрещены |
| R3 | да | резервная копия создаётся и подтверждается успешным тестом восстановления не старше 90 дней |
| R4 | нет | защитное средство включено на всех узлах и имеет актуальный статус |
| R5 | да | межзонный доступ ограничен утверждённой матрицей потоков |
| R6 | да | носитель резервной копии зашифрован; материал восстановления хранится отдельно |
| R7 | нет | события входа, отказа доступа и изменения прав поступают в защищённый журнал |
| R8 | нет | критические обновления установлены либо есть утверждённое исключение |
| R9 | нет | парольная политика соответствует локальному стандарту PP-12 |
| R10 | нет | права пользователей пересмотрены за последние 180 дней |
| R11 | нет | назначены ответственные и канал регистрации инцидентов |
| R12 | нет | на OKFKS-SA23 отключены неиспользуемые сетевые службы |

### Правило решения

Заключение «защищена» возможно только при соответствии всех критических требований и не более двух некритических несоответствий. При отсутствии доказательства ставится отдельный статус, а не автоматически «не соответствует».
