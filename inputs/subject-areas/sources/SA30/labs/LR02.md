# LR02 Расчёт наработки на отказ и среднего времени восстановления по журналу

SA30 Хранилище результатов аттестации

Вы готовите решение для системы «Хранилище результатов аттестации» (OKFKS-SA30). Её критичная функция — запись и выдача подтверждённых результатов. Для освоения метода ниже используется отдельный учебный эпизод. Сервис печати PRINT-01 наблюдался в течение непрерывного календарного окна. Руководителю эксплуатации нужны сопоставимые показатели: средняя наработка между отказами и среднее время восстановления. В журнале есть как аварийные простои, так и плановое обслуживание, которое нельзя считать отказом. Перенос на вашу предметную область выполняется последним действием: необходимо объяснить последствие для конкретного актива, а не только заменить название системы.

Наработка и восстановление отвечают на разные вопросы. Сначала определите базу наблюдения, исключения и число завершённых эпизодов; только затем подставляйте часы в формулы.

Из ЛР01 возьмите правило «сообщение не равно отказу» и способ подтверждения восстановления. Для чисел используйте только журнал текущей работы.

В ЛР03 передайте расчётную таблицу с единицами, исключениями и проверкой баланса. Там новая месячная сводка: переносится метод, а не числовые итоги ЛР02.

## Паспорт применения к выбранному варианту

Система: Хранилище результатов аттестации (OKFKS-SA30).

Критичная функция: запись и выдача подтверждённых результатов.

Активы: результаты, протоколы, журнал изменений.

В отчёте сохраняйте один вариант SA01–SA30 на весь курс. Если исходные эпизоды имеют разные имена узлов или окна наблюдения, переносите метод и структуру доказательств, а не объединяйте их числовые итоги.

## Правила

Отказ начинается в момент утраты печати и заканчивается после успешной контрольной страницы.

Плановое обслуживание M01 исключается из доступного окна и не входит в число отказов.

Перекрывающихся событий нет; единица расчёта — час, допускается десятичная дробь.

Наработка за окно = календарное окно − аварийный простой − исключённое плановое обслуживание.

MTBF для этой работы = суммарная наработка / число отказов; MTTR = суммарный аварийный простой / число отказов.

## Правило округления

Промежуточные длительности сохранять без округления; итоговые показатели округлить до сотых.

## Независимая проверка

Календарные часы должны быть равны сумме наработки, аварийного простоя и исключённого обслуживания.

## Actions

Определите, какие строки журнала входят в расчёт отказов.

Рассчитайте длительность каждой записи и заполните таблицу исходных данных.

Найдите суммарный аварийный простой, суммарную наработку, MTBF и MTTR; запишите формулы с подстановкой.

Проверьте баланс календарного окна и повторите один итоговый расчёт альтернативным способом.

Сделайте краткий вывод о частоте отказов и трудоёмкости восстановления без присвоения системе невыданной нормативной оценки.

Опишите, каким успешным контрольным действием в вашем варианте подтверждается восстановление, и сопоставьте рассчитанный MTTR с C2 после приведения единиц; среднее не доказывает соблюдение предела каждым эпизодом.
