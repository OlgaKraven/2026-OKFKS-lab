# SA14 · ЛР 02 · Расчёт наработки на отказ и среднего времени восстановления по журналу

**Предметная область:** Шлюз учебных уведомлений
**Система:** `OKFKS-SA14`
**Критичная функция:** своевременная доставка уведомлений
**Профиль:** Учётные и интеграционные сервисы (варианты 11–15)

## Рабочая ситуация

Сервис печати OKFKS-SA14 наблюдался в течение непрерывного календарного окна. Руководителю эксплуатации нужны сопоставимые показатели: средняя наработка между отказами и среднее время восстановления. В журнале есть как аварийные простои, так и плановое обслуживание, которое нельзя считать отказом.

### Исходные данные: Rules

Отказ начинается в момент утраты печати и заканчивается после успешной контрольной страницы.

Плановое обслуживание M01 исключается из доступного окна и не входит в число отказов.

Перекрывающихся событий нет; единица расчёта — час, допускается десятичная дробь.

Наработка за окно = календарное окно − аварийный простой − исключённое плановое обслуживание.

MTBF для этой работы = суммарная наработка / число отказов; MTTR = суммарный аварийный простой / число отказов.
